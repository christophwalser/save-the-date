# save-the-date

Save-the-Date-Seite für die Hochzeit von Christoph & Verena am 9. Oktober 2027.

Veröffentlicht über GitHub Pages: <https://christophwalser.github.io/save-the-date/>

## Aufbau

- `index.html`: die komplette Seite, reines HTML und CSS ohne JavaScript
- `assets/img/`: Fotos
- `assets/fonts/`: Schriften (Playfair Display, Hanken Grotesk, SIL OFL 1.1), lokal eingebunden, es gibt keine Anfragen an Google
- `.nojekyll`: GitHub Pages liefert die Dateien unverändert aus

## Hinweise

- Die Seite ist per `noindex` von Suchmaschinen ausgenommen. Wer den Link kennt, kann sie trotzdem aufrufen.
- Änderungen: Datei im Repo bearbeiten und auf `master` pushen, GitHub Pages aktualisiert die Seite nach ein bis zwei Minuten.
